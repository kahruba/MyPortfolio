## 🚀 Getting Started

You can run this portfolio locally on your computer.

### Prerequisites

- A modern web browser
- Git
- Visual Studio Code (recommended)
- Live Server extension for VS Code (optional)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/kahruba/MyPortfolio.git
```

**2. Navigate to the project directory**

```bash
cd MyPortfolio
```

**3. Open the project**

Open the `MyPortfolio` folder in Visual Studio Code.

**4. Run the website**

Open `index.html` directly in your browser, or use the Live Server extension for a local development server.

No Node.js installation or build process is required for the basic static website.

## 🌍 Deployment

This portfolio is hosted using GitHub Pages.

Live URL:

https://kahruba.github.io/MyPortfolio/

To publish updates:

1. Make changes to the website files.
2. Save your changes.
3. Commit and push them to the `main` branch.
4. Wait for GitHub Pages to publish the updated website.

Example Git commands:

```bash
git add .
git commit -m "Update portfolio"
git push origin main
```
